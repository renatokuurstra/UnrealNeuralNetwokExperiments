# ExperimentsECSNN

ExperimentsECSNN is an Unreal Engine project exploring the intersection of **Entity Component System (ECS)** and **Machine Learning (ML)** for vehicle control.

## Project Philosophy: Vibe Coding
This project leverages **vibe coding**. Most of the code is generated by AI agents (like Junie). The goal is to keep human code writing at a minimum, prioritizing architectural intent and rapid iteration over manual micro-optimization. We accept potential hits on code quality when AI hallucinates or is imprecise, as the speed of AI-driven development allows for quick course correction and experimentation.

## Core Features
- **ECS-First Architecture**: Leveraging the `UEcs` plugin (EnTT-based) for high-performance gameplay logic and state management.
- **Machine Learning**: Implementing Genetic Algorithms and Neural Network controllers via the `SimpleML` plugin.
- **Vehicle Training**: A specialized training environment for vehicles using spline-based circuits.
- **Plugin-First Design**: Functional areas are separated into independent, decoupled plugins to maintain a clean project structure.

## Plugins
- **UEcs**: Core ECS framework for Unreal Engine.
- **SimpleML**: Lightweight machine learning utilities, including Genetic Algorithms and Neural Network components.
- **VehicleInterfaces**: Decoupling interfaces for vehicle control, allowing the trainer to work with any vehicle implementation.
- **CircuitGenerator**: Utilities for generating and managing training circuits.

## Requirements
- Unreal Engine 5.7+
- C++20 compatible compiler

## Getting Started
1. Clone the repository including submodules:
   ```bash
   git clone --recursive https://github.com/renatokuurstra/ExperimentsECSNN
   ```
2. Generate project files and build.
3. Open the project in Unreal Editor and explore the `SelfDriving` content folder.
